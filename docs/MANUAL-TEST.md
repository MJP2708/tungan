# คู่มือทดสอบด้วยมือกับกลุ่ม LINE จริง

ทำตามลำดับ ถ้าข้อไหนไม่ผ่านให้หยุดและแจ้ง อย่าข้ามไปข้อถัดไป
ปรับล่าสุด 27 กันยายน 2569 ให้ตรงกับของจริงที่ใช้งานอยู่

## เตรียมก่อนเริ่ม

ระบบจริงตั้งค่าครบแล้ว: แอปอยู่ที่ `https://www.humanmatter.work`
ฐานข้อมูล Neon และเซิร์ฟเวอร์อยู่สิงคโปร์ ตัวตั้งเวลาเตือนคือ cron-job.org
ยิงทุก 15 นาที ช่วง 08:00–21:45 เวลาไทย (GitHub Actions เป็นตัวสำรอง)

ต้องมี:

| ต้องมี | ทำไม |
|---|---|
| มือถือ 2 เครื่อง หรือ 2 บัญชี LINE | ต้องมีคนสั่งงานและคนรับงานคนละคน |
| กลุ่ม LINE สำหรับทดสอบ ที่**ยังไม่มี** OA อื่นอยู่ | หนึ่งกลุ่มมี OA ได้บัญชีเดียว |
| ทั้งสองบัญชีเพิ่ม @ทันงาน เป็นเพื่อน | ไม่เพิ่ม = รับข้อความเตือนไม่ได้ |

> ถ้ากลุ่มมี OA อื่นอยู่แล้ว บอทจะเข้าไม่ได้ **นี่คือข้อจำกัดของ LINE ไม่ใช่บั๊ก**
> ให้ข้ามไปทดสอบข้อ 12 (เส้นทาง DM) แทน

---

## 1. เชิญบอทเข้ากลุ่ม แล้วบอทต้องแนะนำตัว

1. เชิญ @ทันงาน เข้ากลุ่มทดสอบ
2. ผ่านเมื่อ: บอททักในกลุ่มทันที บอกว่าอ่านอะไร เก็บอะไร ลบเมื่อไหร่
   พร้อมลิงก์ `/privacy` และลิงก์เปิดแอป
3. ข้อความนี้ใช้ reply token จึง **ไม่นับโควตา**

## 2. พื้นที่งานของกลุ่มเกิดเอง ไม่ต้องกดอะไร

1. หลังเชิญบอทเข้ากลุ่ม ข้อความต้อนรับต้องบอกว่า "พื้นที่งานของกลุ่มนี้พร้อมแล้ว ไม่ต้องตั้งค่าอะไร"
2. คนที่จะเป็นผู้ดูแล **แท็ก @ทันงาน** ในกลุ่มเป็นคนแรก (เช่นพิมพ์งานแรกในข้อ 3)
3. เปิดแอปจากลิงก์ในข้อความนั้น (หรือจากเมนูด้านล่างแชทของบอท → งานของฉัน)
4. ผ่านเมื่อ: มีพื้นที่งาน**ชื่อเดียวกับกลุ่ม**อยู่แล้ว **โดยไม่ต้องกดปุ่มเชื่อมกลุ่ม**
   และในหน้า ทีม คนที่แท็ก @ทันงาน คนแรกเป็น owner
5. ให้เพื่อนอีกคนพิมพ์อะไรก็ได้ในกลุ่ม แล้วเปิดแอป → เห็นพื้นที่งานเดียวกันทันที (เป็น member)

## 3. ข้อความที่แท็ก @ทันงาน กลายเป็นดราฟต์ที่อ่านรู้เรื่อง

1. พิมพ์ในกลุ่ม โดย**แท็กเพื่อนร่วมทีมจริง ๆ** ด้วยฟังก์ชันแท็กของ LINE:
   `@ทันงาน @<เพื่อน> ส่งใบเสนอราคาให้ ABC พรุ่งนี้ 16:00`
2. ผ่านเมื่อ: บอท**ตอบกลับในกลุ่ม** เป็นการ์ดที่บอก งาน / ใคร / เมื่อไหร่
3. **ชื่องานต้องไม่มี `@ชื่อคน` ติดมาด้วย** และผู้รับผิดชอบต้องเป็นคนที่ถูกแท็ก
   (ระบบใช้ user id จากการแท็กของ LINE ไม่ใช่การเดาจากชื่อเล่น)
4. ตรวจว่าเป็น reply ไม่ใช่ push: ในแอป → ตั้งค่า → โควตาข้อความเดือนนี้
   ตัวเลข **ต้องไม่เพิ่ม**

## 4. ไม่แท็ก = ไม่มีอะไรเกิดขึ้น และไม่เก็บข้อความ

1. พิมพ์ข้อความธรรมดาในกลุ่ม โดยไม่แท็ก `@ทันงาน`
2. ผ่านเมื่อ: **ไม่มี**ดราฟต์เข้ากล่อง และบอทเงียบสนิท
3. ข้อความนั้นระบบเก็บแค่รหัสกับเวลาเพื่อกันงานซ้ำ ไม่เก็บเนื้อความ
   นี่คือข้อที่ทำให้คำว่า "บอทไม่ได้อ่านทุกข้อความ" เป็นจริง

## 5. ยืนยันจากในแชท LINE ได้เลย

1. กดปุ่ม **ยืนยันสร้างงาน** บนการ์ดในกลุ่ม
2. ผ่านเมื่อ: ได้งาน 1 งาน และบอทตอบกลับพร้อมปุ่มสถานะห้าปุ่ม
3. กดปุ่มเดิมซ้ำ → ต้องบอกว่ายืนยันไปแล้ว **ไม่ใช่งานที่สอง**
4. ถ้าวันเวลาหรือคนผิด: กด **เปลี่ยนกำหนดส่ง** / **เปลี่ยนผู้รับผิดชอบ** บนการ์ด
   แก้ได้ในแชทเลย ไม่ต้องเปิดแอป

## 6. แก้ดราฟต์ก่อนสร้าง แล้วค่อยยืนยันในแอป

1. ส่งข้อความแท็กบอทอีกหนึ่งข้อความ แล้วเปิดแอป → แท็บ **LINE**
2. กำหนดส่งต้องอ่านออกเป็นภาษาคน (เช่น "พรุ่งนี้ 16:00") ไม่ใช่ตัวเลขยาว ๆ
3. กด **แก้ชื่อ ผู้รับผิดชอบ หรือกำหนดส่งก่อนสร้าง** → แก้ชื่องาน → **สร้างงาน**
4. ผ่านเมื่อ: งานที่ได้ใช้ชื่อที่แก้ และกำหนดส่งเดิมไม่เปลี่ยนเองถ้าไม่ได้แตะ
5. ถ้ามีดราฟต์ตั้งแต่ 2 รายการ จะมีปุ่ม **ยืนยันทั้งหมด** ลองกดดูหนึ่งครั้ง

## 7. แก้ไขงานหลังสร้างแล้ว

1. เปิดงาน → **แก้ไขงาน · ชื่อ กำหนดส่ง ผู้รับผิดชอบ**
2. เปลี่ยนกำหนดส่งเป็น "พรุ่งนี้" แล้วบันทึก
3. ผ่านเมื่อ: กำหนดส่งเปลี่ยนจริง และเวลาของวันยังเป็นเวลาเดิม

## 8. ปุ่มสถานะ ทั้งในแอปและในแชท

ทำทีละอันด้วยบัญชี**ผู้รับงาน**: รับงาน → ขอข้อมูล → ติดปัญหา → ส่งต่อ → ส่งงาน

ผ่านเมื่อ:
- ทุกปุ่มกดครั้งเดียวติด และสถานะเปลี่ยนจริงทั้งสองฝั่ง
- **ติดปัญหา** เปิดแผ่นเลือกเหตุผล (รอลูกค้า / รอของ / รอคนอื่น / อื่นๆ)
  ไม่ใช่กล่องเทา ๆ ของเบราว์เซอร์ที่ให้พิมพ์ตัวเลข
- เหตุผลเป็นส่วนตัวโดยปริยาย ทีมเห็นแค่ว่า "ติดปัญหา"
- **ส่งงาน** บังคับใส่ลิงก์หลักฐานก่อน (หรือเลือกส่งโดยไม่มีลิงก์อย่างชัดเจน)
- ปุ่มเดียวกันในแชท LINE ให้ผลเหมือนกัน และตอบด้วย reply (โควตาไม่ขึ้น)

## 9. คนสั่งงานตรวจและปิดงานได้

1. สลับไปบัญชี**คนสั่งงาน** → เปิดงานที่ถูกส่งตรวจ
2. กด **ขอแก้** → เลือก 1/2/3 วัน → พิมพ์ว่าต้องแก้อะไร → ส่งกลับ
3. ให้ผู้รับงานส่งตรวจอีกครั้ง แล้วคนสั่งงานกด **อนุมัติ**
4. ผ่านเมื่อ: ทั้งสองปุ่มทำงาน (เคยพังมาก่อน: ปุ่มไม่ส่งอะไรเลยถ้าคนตรวจ
   ไม่ใช่ผู้รับผิดชอบ) และผู้รับงาน **อนุมัติงานตัวเองไม่ได้**

## 10. เตือนถึงตัวคนเดียว ตรงเวลาไทย

1. สร้างงานที่กำหนดส่งอีกประมาณ 1 ชั่วโมง มอบให้ผู้รับงาน
2. รอรอบตัวตั้งเวลา (ไม่เกิน 15 นาที ในช่วง 08:00–21:45)
3. ผ่านเมื่อ: ผู้รับงานได้ **DM ส่วนตัว** ไม่ใช่ข้อความในกลุ่ม
   และในข้อความมีลิงก์ที่กดแล้วเปิดงานนั้นเลย
4. ตั้งค่า → โควตาข้อความ: เพิ่มขึ้น **1 ต่อผู้รับหนึ่งคน**
   (ถ้าเพิ่มเท่าจำนวนคนในกลุ่ม แปลว่าส่งเข้ากลุ่มผิดวิธีและจะเปลืองเงิน)

## 11. คนที่ยังไม่ได้เพิ่มบอทเป็นเพื่อน

1. มอบงานให้คนที่ยังไม่ได้แอดบอท
2. ผ่านเมื่อ: แอปขึ้น**คำเตือนว่าคนนี้รับข้อความส่วนตัวไม่ได้** ไม่ใช่เงียบหาย

## 12. เส้นทางสำรอง: ทักบอทโดยตรง

1. ทักหา @ทันงาน ในแชทส่วนตัว: `ส่งรายงานพรุ่งนี้ 10 โมง`
2. ผ่านเมื่อ: ได้การ์ดให้ยืนยัน และการ์ดบอกด้วยว่าจะลงที่พื้นที่งานไหน
   (บรรทัด `ที่: …`) — ต้องเป็นพื้นที่งานที่คุณใช้ล่าสุด ไม่ใช่สุ่ม
3. พิมพ์ `วิธีใช้` → บอทต้องอธิบายวิธีใช้ (ปุ่มในเมนูล่างก็ส่งคำนี้)

## 13. ข้อมูลต้องไม่ข้ามพื้นที่งาน

1. ให้บัญชี B ที่ไม่ได้อยู่ในพื้นที่งานของ A เปิดลิงก์งานของ A
2. ผ่านเมื่อ: เปิดไม่ได้ และไม่มีข้อมูลของ A โผล่มาเลย

## 14. ลบข้อความใน LINE แล้วข้อความดิบต้องหาย

1. ส่งข้อความแท็ก `@ทันงาน` แล้วกดยกเลิกการส่งใน LINE
2. ผ่านเมื่อ: ดราฟต์ในกล่องไม่เหลือเนื้อความเดิม
   (ระบบลบทั้งสำเนาในกล่องและสำเนาใน log เหตุการณ์)

## 15. มือถือจริงใน LINE WebView

เปิดจากในแอป LINE ทั้ง iPhone และแอนดรอยด์รุ่นกลาง ใช้คีย์บอร์ดไทย

ผ่านเมื่อ:
- เลือกพื้นที่งานได้ภายใน 2 แตะ
- สร้างงาน เลือกวัน เลือกเวลา และส่งงานได้
- **ไม่มีกล่องไหนหลุดขอบจอ และไม่มีการเลื่อนซ้ายขวา** ตอนคีย์บอร์ดเด้งขึ้นมา
- ปุ่มทุกปุ่มกดติดตั้งแต่ครั้งแรก (ทุกปุ่มใหญ่อย่างน้อย 44×44)

## 16. เก็บกวาดหลังทดสอบ

- ตั้งค่า → **เปลี่ยนชื่อ** พื้นที่งานได้ถ้าชื่อไม่ตรง
- ตั้งค่า → **ยกเลิกการเชื่อม** ถ้าต้องการหยุดรับข้อความจากกลุ่มนั้น
- ทดสอบแล้วให้บันทึกไว้ว่าข้อไหนไม่ผ่าน พร้อมเวลาโดยประมาณ
  (เวลาช่วยหา log ของเหตุการณ์นั้นได้)
