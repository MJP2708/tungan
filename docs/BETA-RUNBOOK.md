## เช็ก 30 วินาที ว่าระบบยังดีอยู่

```
curl -s https://www.humanmatter.work/api/health
```

ต้องได้ `"ready":true` และ `"database":"ok"` ถ้าไม่ใช่:

| ค่าที่เห็น | แปลว่า | ทำอะไร |
|---|---|---|
| `"database":"unreachable"` | รหัสผ่าน Neon เปลี่ยน หรือฐานข้อมูลหยุด | เอา connection string ใหม่จาก Neon ใส่ใน Vercel แล้ว **Redeploy** (ค่าใหม่มีผลเมื่อ deploy เท่านั้น) |
| `"ready":false` แต่ database ok | มี env var หาย | ดูในคำตอบว่าตัวไหนเป็น `false` แล้วใส่กลับใน Vercel |
| เปิดไม่ขึ้นเลย | Vercel ล่ม หรือ DNS | ดู vercel.com → Deployments |

`remindersLastSentAt` คือเวลาที่ส่งเตือนล่าสุด ถ้าเป็น `null` แปลว่ายังไม่เคยมีเตือนถึงกำหนดเลย
(ไม่ใช่ความผิดพลาดถ้ายังไม่มีงานที่ตั้งเวลาไว้)

## เตือนไม่ออก

ไล่ตามลำดับนี้:

1. **ผู้รับแอดบอทหรือยัง** — ไม่แอด = ส่งไม่ได้ ระบบจะบันทึกเหตุผลไว้ ไม่ได้เงียบหาย
2. **ตัวตั้งเวลายังยิงอยู่ไหม** — เปิด cron-job.org ดู History ต้องเป็น 200 ทุก 15 นาที
   ถ้า 401 แปลว่า `CRON_SECRET` ใน Vercel กับใน cron-job.org ไม่ตรงกัน
3. **ถึงเวลาส่งหรือยัง** — เตือนจะถูกเลื่อนออกจากช่วงเงียบ (ค่าเริ่มต้น 21:00–08:00)
4. **โควตาเดือนนี้เต็มหรือยัง** — ในแอป → ตั้งค่า → โควตาข้อความเดือนนี้
5. ถ้าส่งไม่สำเร็จ 5 ครั้ง ระบบจะหยุดและทำเครื่องหมายว่า `failed` พร้อมเหตุผล ไม่วนส่งซ้ำไม่จบ

## โควตาข้อความ LINE — เรื่องเงิน

แผนฟรีให้ **300 ข้อความ/เดือน** นับ **ต่อผู้รับหนึ่งคน**
ข้อความตอบกลับในกลุ่ม (reply) **ไม่นับ** — เฉพาะ DM เตือนที่นับ

ทีม 10 คน เตือนวันละ 2 ครั้ง 22 วันทำการ = 440 ข้อความ/เดือน **ทีมเดียวก็เกินแล้ว**
ดังนั้น:

- ระบบรวมเตือนของคนเดียวกันเป็นข้อความเดียวอยู่แล้ว (digest)
- ใกล้เต็มโควตา บอทจะบอกในข้อความว่ากำลังรวบให้สั้นลง ไม่ใช่เงียบไปเฉย ๆ
- **ก่อนรับทีมที่ 2 ให้ซื้อ LINE OA Basic** (1,280 บาท + VAT, 15,000 ข้อความ)
  แล้วแก้เพดานในฐานข้อมูล:
  `update workspace set monthly_message_cap = 15000;`

## AI (Jev)

ตอนนี้ปิดอยู่ทั้งระบบ เพราะยังไม่ได้ใส่คีย์

- เปิด: ใส่ `TYPESAFE_API_KEY` ใน Vercel (server-only) → Redeploy → ในแอปหน้า AI จะมีสวิตช์
- เพดาน: วันละ 20 ครั้ง และรวมทั้งหมด 50 ครั้งต่อพื้นที่งาน
  แก้ได้ที่ `workspace.ai_daily_cap` และ `workspace.ai_allowance`
- **ปิดฉุกเฉินทั้งระบบ**: ตั้ง `AI_KILL_SWITCH=1` ใน Vercel แล้ว Redeploy
  (ไม่ต้องแก้โค้ด ไม่ต้องปิดทีละพื้นที่งาน)
- AI ใช้เฉพาะตอนกฎอ่านไม่ออก และคนยังต้องกดยืนยันเสมอ ถ้าโควตา AI หมด
  ระบบยังอ่านด้วยกฎ สร้างงานเอง และเตือนได้ตามปกติ

## คำถามที่ทีมมักถามช่วงเบต้า

**"บอทอ่านข้อความเราทั้งหมดเหรอ"**
ไม่ อ่านเฉพาะข้อความที่ติด @ทันงาน ข้อความอื่นเก็บแค่รหัสกับเวลาเพื่อกันงานซ้ำ
ไม่เก็บเนื้อความ และลบรหัสภายใน 30 วัน — หน้า `/privacy` อธิบายไว้ครบ

**"ทำไมเชิญบอทเข้ากลุ่มไม่ได้"**
กลุ่มหนึ่งมีบัญชีทางการได้บัญชีเดียว ถ้ากลุ่มมีบอทอื่นอยู่แล้ว ต้องใช้เส้นทางทักตรง (DM)

**"ทำไมรายชื่อไม่ครบ"**
ดึงรายชื่อทั้งกลุ่มต้องใช้บัญชี Verified (950 บาท) ตอนนี้จะรู้จักเฉพาะคนที่เคยพิมพ์
หรือเคยถูกแท็กในกลุ่ม — แอปบอกเรื่องนี้ไว้แล้ว ไม่ใช่ของเสีย

**"ขอลบข้อมูล"**
ทักหา OA แล้วลบแถวของคนนั้นใน `line_user` ผลที่ตามมา:

- **ลบตาม**: การเป็นสมาชิกพื้นที่งาน, การเตือนที่ค้างอยู่, คำถามที่ถามคนนั้น,
  เซสชัน และรายชื่อในกลุ่ม
- **ไม่ถูกลบ**: งานที่เคยได้รับมอบหมายหรือเคยสั่ง จะอยู่ต่อแต่ชื่อคนหายไป
  (เพื่อไม่ให้ประวัติงานของทีมหายไปด้วย)

ถ้าต้องการลบงานของคนนั้นด้วย ต้องลบงานก่อน แล้วค่อยลบผู้ใช้

## ข้อมูลเก็บนานแค่ไหน

| อะไร | นานแค่ไหน |
|---|---|
| ข้อความต้นฉบับที่ติด @ทันงาน | 7 วัน หรือลบทันทีเมื่อยืนยัน/ปิดทิ้ง/ยกเลิกการส่ง |
| รหัสเหตุการณ์ (กันงานซ้ำ) | 30 วัน |
| งานที่ยืนยันแล้ว | จนกว่าจะลบ |

งานเก็บกวาดนี้ทำงานพ่วงไปกับรอบส่งเตือน ไม่ต้องสั่งเอง

## เปลี่ยนความลับ (ทำเมื่อหลุด หรือตามรอบ)

ทำทีละอย่างแล้วเช็กทันที เพราะระหว่างเปลี่ยนบอทจะใช้งานไม่ได้ชั่วคราว:

1. LINE console → ออก channel secret / access token ใหม่
2. ใส่ใน Vercel → **Redeploy** (ค่าใหม่มีผลเมื่อ deploy)
3. เช็ก: LINE console กด **Verify** ที่ webhook ต้องได้ 200
4. แก้ `.env.local` ในเครื่องให้ตรงกันด้วย

> เปิด **Webhook redelivery** ไว้ในคอนโซล LINE ข้อความที่เข้ามาระหว่างเปลี่ยนจะถูกส่งซ้ำ
> ระบบกันข้อความซ้ำอยู่แล้ว จึงไม่เกิดงานซ้ำ

## ดู log จริง

Vercel → Project → Logs กรองด้วยคำเหล่านี้:

| คำ | หมายถึง |
|---|---|
| `[webhook][signature-rejected]` | มีคนยิง webhook ปลอม หรือ secret ไม่ตรง |
| `[webhook][processing-error]` | ประมวลผลข้อความไม่สำเร็จ (ดูข้อความต่อท้าย) |
| `[cron] reminders` | รอบส่งเตือน พร้อมจำนวนที่ส่ง/ล้มเหลว |
| `[cron][rejected]` | ตัวตั้งเวลาใช้ secret ผิด |
| `[ai]` | AI ถูกปฏิเสธหรือใช้ไม่ได้ (จะไม่ทำให้อย่างอื่นพัง) |
